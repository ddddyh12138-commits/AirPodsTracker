# 耳机时光 · 签名与首次设置

本项目面向 iOS 17 及以上的 iPhone。云端打包脚本生成的是未签名设备包，需要你自己的 Apple 开发签名才能安装。

## 使用 iLoader

1. 将 iPhone 连接电脑，在手机上信任这台电脑。
2. 打开你已有的 iLoader，在 iLoader 中登录自己的 Apple ID。
3. 选择导入 IPA，选中 `AirPodsTracker-unsigned.ipa`，按 iLoader 提示完成签名与安装。
4. 如果系统要求开发者模式或信任开发者，请按手机与 iLoader 的实际提示处理。

不要把 Apple ID 密码或签名证书发给 Codex。iLoader 的官方说明确认其支持导入 IPA；具体界面以你安装的版本为准：[官方仓库](https://github.com/nab138/iloader)。本交付未操作手机或验证安装成功。

## 首次建立自动记录

打开 App 建立耳机档案，然后根据 App 内的自动化向导，在系统「快捷指令」建立两条个人自动化：

1. 所选耳机蓝牙连接 → 立即运行 → 「记录耳机连接」 → 选择刚建立的档案。
2. 同一耳机蓝牙断开 → 立即运行 → 「记录耳机断开」 → 选择同一档案。

实际连接、断开一次，再回到 App 核对开始与结束记录。配置成功后，正常使用无需手写这两个时间；漏触发或冲突时才补录。记录的是动作执行时间，仍需验证你的 iOS、耳机型号与锁屏条件下的实际触发效果。

电量读取采用手动记录或截图 OCR 后确认；本 App 没有将历史读数当成实时电量，也不会通过连接时长换算电池健康。
