## 一、项目概述

- **项目名称**: AirPodsTracker
- **平台**: iOS 17+
- **技术栈**: SwiftUI + SwiftData + AVFoundation + Swift Charts
- **语言**: Swift 5.9+
- **功能目标**:
  1. 自动记录每次 AirPods 使用时长（连接 → 断开）
  2. 追踪充电盒充满一次后的总可用时长（含耳机反复从盒子充电）
  3. 使用统计和图表
  4. 本地通知提醒

## 二、iOS 平台关键限制（必须了解）

| 限制 | 说明 | 解决方案 |
|------|------|----------|
| 无法直接读取 AirPods 电量 | Apple 不提供第三方 API | 用户手动输入 + 基于时间估算 |
| 后台运行受限 | App 被系统挂起后无法持续计时 | 记录时间戳，回到前台时补算 |
| CoreBluetooth 不适用 | AirPods 不暴露标准 BLE 电池服务 | 使用 AVAudioSession 替代 |
| AirPods MAC 地址随机轮换 | 无法通过蓝牙地址追踪 | 通过音频路由的 portName 识别 |

## 三、核心技术方案

### 3.1 AirPods 连接检测（核心）

使用 `AVAudioSession.routeChangeNotification` 监听音频路由变化：

```swift
// 监听连接/断开
NotificationCenter.default.addObserver(
    forName: AVAudioSession.routeChangeNotification,
    object: nil, queue: .main
) { notification in
    guard let reasonValue = notification.userInfo?[AVAudioSessionRouteChangeReasonKey] as? UInt,
          let reason = AVAudioSession.RouteChangeReason(rawValue: reasonValue) else { return }
    
    switch reason {
    case .newDeviceAvailable:   // 新设备连接
        checkIfAirPods(connected: true)
    case .oldDeviceUnavailable: // 设备断开
        checkIfAirPods(connected: false)
    default: break
    }
}

// 判断是否为 AirPods
func checkIfAirPods(connected: Bool) {
    let route = AVAudioSession.sharedInstance().currentRoute
    for output in route.outputs {
        if (output.portType == .bluetoothA2DP || output.portType == .bluetoothHFP),
           output.portName.contains("AirPods") {
            // 确认是 AirPods，执行连接/断开逻辑
        }
    }
}
```

## 四、数据模型设计（SwiftData）

### 4.1 UsageSession — 单次使用会话

```swift
@Model
class UsageSession {
    var id: UUID = UUID()
    var startTime: Date                    // 连接时间（取出耳机）
    var endTime: Date?                     // 断开时间（放回盒子），nil = 进行中
    var deviceName: String                 // 如 "AirPods Pro"
    var startBattery: Int?                 // 开始电量（用户可选输入）
    var endBattery: Int?                   // 结束电量（用户可选输入）
    var sessionIndex: Int?                 // 本盒子周期内第几次使用
    
    @Relationship var caseChargeCycle: FullCaseChargeCycle?  // 所属盒子充电周期
    
    var duration: TimeInterval {
        (endTime ?? Date()).timeIntervalSince(startTime)
    }
    
    var formattedDuration: String {
        let h = Int(duration) / 3600
        let m = (Int(duration) % 3600) / 60
        return h > 0 ? "\(h)小时\(m)分钟" : "\(m)分钟"
    }
}
```

### 4.2 FullCaseChargeCycle — 充电盒完整周期

追踪从「盒子充满电」到「盒子没电」之间所有使用会话的总时长。

```swift
@Model
class FullCaseChargeCycle {
    var id: UUID = UUID()
    var startTime: Date                    // 盒子充满电的时间
    var endTime: Date?                     // 盒子没电/再次充电的时间
    var deviceModel: String                // AirPods 型号
    var isActive: Bool = true              // 是否为当前进行中的周期
    
    @Relationship(deleteRule: .cascade, inverse: \UsageSession.caseChargeCycle)
    var sessions: [UsageSession] = []
    
    // ✅ 核心：盒子满电后总共用了多久
    var totalUsageTime: TimeInterval {
        sessions.reduce(0) { $0 + $1.duration }
    }
    
    var formattedTotalUsage: String {
        let h = Int(totalUsageTime) / 3600
        let m = (Int(totalUsageTime) % 3600) / 60
        return "\(h)小时\(m)分钟"
    }
    
    var sessionCount: Int { sessions.count }
    
    // 对比官方续航
    var officialMaxHours: Double {
        Self.officialTotalHours[deviceModel] ?? 30.0
    }
    
    var officialComparisonPercent: Int {
        Int((totalUsageTime / (officialMaxHours * 3600)) * 100)
    }
    
    var estimatedRemainingTime: TimeInterval {
        max(0, officialMaxHours * 3600 - totalUsageTime)
    }
    
    var formattedRemainingTime: String {
        let remaining = estimatedRemainingTime
        let h = Int(remaining) / 3600
        let m = (Int(remaining) % 3600) / 60
        return "\(h)小时\(m)分钟"
    }
    
    static let officialTotalHours: [String: Double] = [
        "AirPods Pro 2": 30.0,
        "AirPods 4": 30.0,
        "AirPods 3": 30.0,
        "AirPods Pro": 24.0,
        "AirPods 2": 24.0,
        "AirPods Max": 20.0,
    ]
}
```
